# Fontes oficiais consultadas

| Serviço | Fonte | Uso validado |
|---|---|---|
| CoinGecko | [Trending Search List](https://docs.coingecko.com/reference/trending-search) | Endpoint `GET /search/trending`, resultados de moedas/NFTs/categorias e cache documentado |
| GDELT | [Data and APIs](https://www.gdeltproject.org/data.html) | Dados abertos e APIs JSON em tempo real, incluindo DOC API |
| Binance | [Spot Testnet REST API](https://developers.binance.com/en/docs/products/spot/testnet/rest-api) | Contrato oficial do ambiente de teste Spot |

As fontes foram usadas apenas para validar contratos e disponibilidade dos provedores. Nenhuma credencial foi incluída, e nenhum dado externo foi tratado como autorização para negociação real.

| Binance Demo | [How to Use Binance Demo Trading?](https://www.binance.com/en/support/faq/detail/9be58f73e5e14338809e3b705b9687dd) | Ambiente virtual, diferenças em relação ao live e funcionalidades não suportadas |
| Binance Testnet | [Testnet General Info](https://developers.binance.com/en/docs/products/spot/testnet/general-info) | Limites de IP, ordens, filtros de exchange e filtros de símbolo |
| Binance market data | [General REST API Information](https://developers.binance.com/en/docs/products/spot/rest-api) | Endpoint público recomendado, rate limits, backoff e respostas de erro |
